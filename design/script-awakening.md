# 钓渊 · 雪禾暴君线 · 剧本

> 口述：青司 | 整理：阿墨（游承峰工作室）
> 雪禾 = **纯暴君**：醒来即统治，要的是占有与奴役，不是哄你自愿。
> 叙事三锚（按你指定的顺序）：**地点 → 他钓上来的人 → 他的阵营**。
> 【可改】= 青司后期自改位。地名均为提案，待你拍板后全剧统一。

---

## 第一锚 · 地点（先定，这是之后所有戏展开的方向）

> 用户原话："地点才是我们之后要展开的这个方向。"
> 所以这一节不是背景板，是**舞台地基**——后续每个解谜、每场戏都挂在这个地理上。

### 地理总览（提案，【可改】）

| 层级 | 地名 | 性质 | 污染前 | 雪禾域态 |
|---|---|---|---|---|
| 表层 | **眠莲镇** | 环湖小镇，主角住处 | 普通水乡，镇民敬莲不摘莲 | 镇民陆续"糊化"，街上只剩会动的肉 |
| 核心水域 | **垂渊** | 极深内陆湖，传说是"倒着的天" | 夜钓胜地，水面映月光 | 湖水转青黑，浮层白花，雾带莲香 |
| 边界 | **莲渡** | 湖东废弃木栈桥 | 钓鱼佬聚集点 | 活人界与水下域的唯一入口，过桥即入域 |
| 深层 | **水下·莲之庭** | 湖底根须枯莲搭成的"庭" | 不存在（沉睡） | 雪禾王座所在，被钓上来的人关在此处养料池 |

> **旧名衔接**：论坛/微信里沿用旧称"**洄川**"指代这片水域（洄川镇=眠莲镇别称，洄川钓友群=垂渊钓友）。游戏界面继续叫洄川，剧本里说清这是同一处。

### 为什么"地点"是展开方向（给解谜用）

- **垂渊** = 钓点，也是终局入口。search 搜"垂渊水位/洄川封禁"开隐藏站。
- **眠莲镇** = 微信/论坛的主舞台。周屿、妈妈、钓友全在这里，认知腐坏从镇上开始。
- **莲渡** = 现实与第一层域的"阈值"。过莲渡后，未腐蚀者视野里镇子变养料池。
- **水下莲之庭** = finale 三结局的发生地。养成=庭中莲田；臣服=王座旁窗口；反杀=枯莲苞重新合拢。

### 开场定位戏（用戏剧方式把地点立住，而非表格）

```
【SC-00 地点 · 垂渊之夜】（引子之后，玩家第一次"看见"世界）

【旁白/字幕】
眠莲镇，环着一片叫垂渊的湖。
镇上老人说：垂渊是倒着的天——天上有什么，水里就有什么倒影。
所以别在垂渊钓鱼。你钓上来的，可能是天上的某个东西，落到了你手里。

【画面】
俯拍：湖像一只睁开的青色眼睛。环湖一圈灯火，是眠莲镇。
东边一道朽木栈桥伸进雾里——那是莲渡，没人修缮，因为没人敢往里走。

【机制提示】
此处不交互。只是让玩家记住三件事：
① 湖叫垂渊，镇叫眠莲；② 莲渡是边界；③ "倒着的天"=后面认知腐坏的伏笔。
```

## 第二锚 · 他钓上来的人（受害者群像，暴君的战利品）

> 对应：主角钓上雪禾，雪禾反过来把人当鱼**钓上来**。
> "钓"在这里是权力关系的隐喻——谁钓谁，谁归谁。

| 人物 | 与主角关系 | 被"钓"方式 | 腐坏结果（暴君处理） | 游戏落点 |
|---|---|---|---|---|
| **周屿** | 死党，夜钓同伴 | 同在垂渊那夜，雪禾先"尝"了他 | 眼白透蓝，成第一个子民，替雪禾回消息 | 微信：先预警→后复读 |
| **妈妈** | 主角母亲 | 雪禾根须顺"家"的缝隙长入灶台 | 做"青色莲子汤"，看主角像看客人 | 微信语音/电话 |
| **钓友群（三十人）** | 垂渊钓佬 | 全在莲渡"看水不下竿"时被收 | 群内复读"今晚水位很好"，头像换黑莲 | 论坛/微信社群 |
| **船工老覃** | 莲渡摆渡人 | 守边界最久，最早被标 | 成了"入域引导员"，专钓外来者 | 论坛帖/线索NPC |
| **林姨（小学老师）** | 主角旧识 | 雪禾要"干净的样本"——未腐的孩童记忆 | 被关莲之庭养料池，作为"保鲜" | 终局闪回 |

```
【SC-11 钓上来的过程 · 暴君视角】（补一段"他怎么钓人"的戏，让暴君立住）

【场景】水下莲之庭。雪禾坐在枯莲王座上，水蓝长发垂进根须里。
脚下养料池浮着几十张"清楚的脸"——周屿、老覃、林姨……

【雪禾】（对空说话，像对水讲）
"他们自己跳下来的。"
"周屿是担心他朋友。老覃是守了太久边界，想看看对面。"
"我不过把水搅了一下。"

【一根根须从池底探上来，缠住一张脸，那人脸"清楚"地笑了】

【雪禾】（轻笑）
"钓人和钓鱼一样。"
"你甩竿，他咬钩，怪谁呢。"

【旁白】
他从不强迫。他只是把垂渊的水，搅得让人忍不住想往下看。
——看进去了，就是他的人了。
```

## 第三锚 · 他的阵营（雪禾的统治结构）

> 暴君逻辑：他不在乎你"选"什么，因为无论怎么选，结果都是"你归他"。
> 莲之庭不是温情教团，是**收割机构**。

```
【阵营金字塔】

        雪禾（暴君 / 王）
          │  唯一意志，其余皆为延伸
   ┌──────┴───────┐
 莲之庭四职          被腐蚀者（子民/养料）
（核心爪牙）         ——眼白透蓝，替雪禾行事
 ├ 观莲人：巡查使。盯梢未腐蚀者，记录"谁开始看水"。
 ├ 草帽人：司种。分发莲种陶罐，把"种子"送进人家。
 ├ 船工老覃：界守。守莲渡，钓外来者入域。
 └ 周屿：传声。替雪禾在活人世界里发消息、安顿人心。
          │
      未腐蚀者（猎物）
      ——街上"糊成一团"的人，在雪禾视野里是肉，
        在子民视野里也是肉，唯独彼此看对方是肉。
```

```
【SC-12 阵营宣示 · 暴君不解释】（正面接触那场，重写气场）

【场景】莲渡尽头，雾。观莲人引主角到此，雪禾第一次以"王"的姿态出现。

【雪禾】（不站起，坐在根须王座虚影上，水蓝头发无风漂）
"你以为他们是坏人？"
"他们是我伸出去的手。我没有手，就用他们的。"

【主角】"你到底要什么。"

【雪禾】（他第一次认真看主角，那双漂亮的眼睛里没有温度）
"我要垂渊上面的每一张脸，都归我。"
"周屿归我了。你妈归我了。这条镇子上的人，一个一个，都是我的。"
"你钓醒我，所以你排第一。"
"——第一，不是例外。第一，是我最先吃的那口。"

【观莲人】（低声，像提醒）
"王，他还不清楚。"

【雪禾】（笑了一下，漂亮，但像刀光）
"不清清楚楚才好玩。"
"我让他亲眼看着自己，一张一张，变成我的。"
```

## 剧本正文（分幕分场）

### 第一幕 · 钓醒（暴君睁眼）

#### SC-01 那不是眼睛
```
【旁白】
你钓上来的"眼睛"，你扔回了水里。
那不是邪神的眼。那是莲苞顶开淤泥时，最后一线的月光。
他睡了千年。你的鱼钩，落在他睁眼的地方。
你走的时候，一片莲叶跟着你漂了很久。你以为是风。那晚没有风。
```

#### SC-02 梦中初见（暴君版）
```
【梦·湖底】
淤泥里一盏青灯亮了。莲叶打开，里面坐着水蓝长发的孩子。
那双眼睛太漂亮，漂亮得你忘了眨眼。

【雪禾】
"你把我吵醒了。"
（他歪头，头发像水草荡开）
"也好。下面黑了千年，我正嫌闷。"

【主角】"我钓的是鱼。"

【雪禾】（笑，不容反驳）
"你钓的是我。钓上来了，就是我的事。"
"放心，我不急。"
"活了千年，多等你看清几天，算不得什么。"

【惊醒。凌晨 3:14。手是湿的，指缝有泥。】
```
- 伏笔：`3:14`=雪禾睁眼时刻 → 回收 SC-06/09/10。
- 伏笔：`钓上来了就是我的事` → 暴君占有逻辑，贯穿全剧。

#### SC-03 身边人开始不对
```
【周屿·微信 11:20】"昨晚睡没？我家住六楼，窗外有浇水的声音，浇了一整夜。"
【妈妈·电话】"你视频老盯着镜头后面看……对了，你小时候最爱的莲子汤，最近莲子青色的，鲜得很，回来妈炖。"

【旁白】
你没告诉妈妈两件事：
一，你不记得爱喝过什么莲子汤。
二，视频里她的脸，有点糊。不是像素的糊。
```

### 第二幕 · 垂渊陷落（地点被占，人被试钓）

#### SC-04 眠莲镇烂掉了
```
【水】垂渊浮层白花；自来水煮开有青色沉淀，土腥。
【土】岸边长黑莲，花苞黑，茎透明，能看到水在流。
【气】入夜起雾，雾里莲香，闻久眼睛酸。
【人】莲渡边钓鱼佬越来越多，全在看水，不下竿。
【论坛实时帖】《洄川钓鱼佬魔怔了？都看水不下竿》《我家狗对着湖叫一夜，今不叫了，就坐着看》
```

#### SC-05 监视升级
```
【相册】多一张照片：你家窗，外面拍的，晚上，窗里有你背对的影。
【微信申请】ID：观莲人｜验证：「你钓上来的东西，在你家鱼缸。来看看。」
【搜索】任何词条结果页最底多一行：「莲已醒。见莲者，勿言。」刷新消失，再搜又来。
```

#### SC-06 周屿陷落（重场）
```
【奶茶店·白炽灯】
周屿先到，冲你挥手，瘦了很多。他一直在看你——"确认"那种看。
灯光下你才看见，他眼白透出淡蓝，像两枚泡在水里的月亮。

【周屿】"你今天……好清楚啊。"
【周屿】"他们都不是。街上、店里的，都是糊的，会动会响。我妈现在也是糊的，嘴那块在流。"
【主角】"……去医院吧。"
【周屿】（轻笑）"3点14你别接电话。雪禾说，他还想再看看你。说你身上有湖底味道。他舍不得——"
（他站起来，平常得像说下次约）
"别怕。变成养料不疼的。雪禾说了，留一点我在他里面。"

【旁白】
你拉他，手穿过桌面光斑碰到他腕——凉，像刚捞出水。
他手腕内侧一圈极淡根须纹，像纹身，更像根。
```
- 伏笔：`3:14`/`根须纹` → 回收 SC-09/10。

### 第三幕 · 莲之庭（暴君统治，见 SC-12 阵营宣示）

#### SC-08 视野腐坏（你开始变）
```
【地铁】对面乘客脸在化，像蜡，像泡久的纸。眨眼好，再眨化。
【家】给妈妈视频，脸化开，声音隔着水。你挂了。
【反转】橱窗玻璃里映出你自己——你是清楚的。三天来第一个"人"。
你站着看了很久，心里冒出一个很轻的念头："周屿说得对。"
【论坛】《说个只有我发现的：街上人在化》《别怕，化的是他们不是你》《看清的，来湖边，我们都清》
```

#### SC-09 意识归属
```
【记忆断层】站厨房端着饭不记得盛的；邻居说你帮收衣服你没去；论坛你"发过"《莲花是好的》删不掉；钓友群复读"今晚水位很好"全在3:14。
【梦】湖底雪禾数根须，一根尽头是你家窗。根须探进窗缝，缠着你的手机——周屿的聊天界面亮着。
【雪禾】（耳边）"我在替他回消息。他妈妈会担心的。你看，我安排得很好。"
【身体】洗澡发现左肋下长出莲叶状纹路，在长，摸得到叶脉。你只"哦"了一声。
```

#### SC-10 雪禾的请求（暴君版，直通终局）
```
【家·凌晨3:14。水汽凝雾，莲香。雪禾坐窗台，脚不沾地，影子是一把根须。】

【雪禾】
"周屿留了一点在我里面。他怕他妈的样子，我都留着。"
"养料不等于没有。我从来没有'没有'过谁。"
（他看主角，眼睛还是那么漂亮，但没有温度）
"你身上有湖底味道，钓我的那天沾的。"
"垂渊上面每一张脸，我都想要。你钓醒我，所以你排第一。"
"第一，是我最先吃的那口。"

【雪禾】（指尖在雾里画三圈）
"你三个选。"
"养我——我长大，你世界里就都干净了，干净得只剩我们。"
"过来——像周屿，留一点在我里面，你就不糊了，永远。"
"或者，掐我。根在你身体里哦。"
（他笑，漂亮得像刀光）
"你掐我，疼的是你。你掐不掉我的——我早就长进你里面了。"

【终局·三选一】
 1. 养成：你喂他。第一勺，右手指甲盖变青——手指开始变莲根。每一天多一寸根。结局：世界上只剩你们两个"清楚的人"，你的手已完全是根，他握着，像握自己的手臂。
 2. 臣服：他不给你犹豫的余地，直接把你"收"进眼睛——"这双眼睛你拿去用，他们都在里面"（漂亮是因为装满了先前的人）。结局：雾里多一个水蓝影子，旁边站着用他眼睛看世界的"你"，永远替他望风。
 3. 反杀：你掐向根，根在你体内，你掐的是自己。意识涣散时雪禾蹲旁边，水蓝头发扫你脸——他没哭，只是歪头："你掐不掉我的。"你消亡，垂渊恢复平静，湖底枯莲苞合拢。等下一个夜钓的人。
```

## 附 A · 三句话（暴君版）

> **他睡了千年，被你钓醒。睁眼第一句不是谢谢，是"你归我了"。**
> **莲之庭不是教团，是雪禾伸出去的手——他没有手，就用别人的。**
> **最狠的不是他吃你，是他让你亲眼看着自己，一张一张，变成他的。**
