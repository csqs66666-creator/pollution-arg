## 4. 推进策略：垂直切片先行
为避免假桌面工程一次铺太大崩，按"垂直切片 → 铺开"推进：

- **切片 1**：假桌面外壳（图标网格 + 任务栏 + 进入动效）+ 一眼场景（圣临之眼 climax 用 CRT 眼阵 + 眼睛拼贴）
- **切片 2**：假聊天（微信已 v2，复用到桌面 app 窗口里）+ 假论坛（论坛已 v2，复用到桌面 app 窗口里）
- **切片 3**：剧情导航 + 桌面图标路由串联 + 结局回桌面

切片 1 出来用户验收后，再批量铺其他 app。

## 7. 已知风险
- **沙箱网络不稳** → 外链/图床/CDN 预览阶段可能掉链（你本地有网就好；部署走 git push）
- **假桌面工程量大** → 垂直切片策略缓解，但不排除切片 1 工期 > 预期
- **pin 是真实照片** → 必须做档案质感处理；直接贴会破坏沉浸感
- **砍 shake = 全站动效重写** → 会连带 typography 几个键帧一起重审，预算留足
- **GitHub Pages 部署** → 首次需建仓 + git init + push；需要你提供 GitHub 账号或授权连接（凭据缺失时我打包你手动推）
